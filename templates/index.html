Defensive Standards Alignment

Every audit control maps directly to recognized cybersecurity baselines and exploit mitigation guides:

Network Surface

Audits Windows Defender Firewall profiles, enforces Network Level Authentication (NLA) on RDP, and confirms legacy SMBv1 protocol is inactive.

Ransomware & Malware

Validates Microsoft Defender Real-Time Protection, signature update freshness, and Controlled Folder Access to defend user files against ransomware.

Hardening & Forensics

Verifies User Account Control (UAC) enforcement, disables unused local Guest accounts, and activates PowerShell Script Block Logging (Event ID 4104).

Educational Scope & Limitations

Cyber Mistake Detector is an educational defensive auditing tool. Passing baseline configuration checks confirms adherence to recommended hygiene practices, but does not guarantee total protection from zero-day exploits or active malware infections.
